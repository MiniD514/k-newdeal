H-MIRAGE 프롬프트 생성기

설정과 영어 설명을 조합해 사실적인 다중스펙트럼 디코이 이미지 프롬프트를 만드세요.

HTML + JavaScript · 오프라인 사용

01 / 기본 구성

프리셋을 바꾸면 피사체·시험장·내부 구성·제외 요소 설명이 갱신됩니다. 상세 문구는 아래에서 자유롭게 수정하세요.

02 / 영어 설명 편집

입력 내용은 번역하지 않고 그대로 반영합니다. 화면 비율·장면 비중·센서 패널은 기본 구성에서 관리합니다.

03 / 생성된 영어 프롬프트

설정 변경 시 자동 생성됩니다. 결과는 직접 수정할 수 있으며, 설정을 다시 바꾸면 재생성됩니다.

이미지 생성용 프롬프트 작성 도구입니다. 이미지는 별도의 이미지 생성 서비스에서 생성하세요. 기본 설명은 독립적인 가상 제품 제안이며 공식 발표 제품을 의미하지 않습니다. 설정 저장은 현재 브라우저를 사용하며, 다른 기기로 옮길 때는 JSON 또는 HTML 다운로드를 사용하세요.
